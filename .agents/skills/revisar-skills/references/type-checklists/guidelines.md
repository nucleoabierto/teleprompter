# Guidelines

Skills que proveen reglas prescriptivas durante implementación.

## Checklist requerido

- Reglas avoid/prefer explícitas
- Ejemplos bueno/malo
- Self-check checklist antes de terminar
- Cuándo aplicar las guidelines

## Checklist recomendado

- Referencia a dominio o contexto
- Excepciones a las reglas
- Integración con otros skills

## Anti-patrones

- Reglas sin ejemplos
- Guidelines sin self-check
- Reglas contradictorias
