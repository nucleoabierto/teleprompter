# Domain-guide

Skills de referencia o guía de convenciones sin estructura prescriptiva.

## Checklist requerido

- Propósito y alcance claros
- Estructura navegable (TOC si >100 líneas)
- Referencias cruzadas relevantes

## Checklist recomendado

- Ejemplos de aplicación
- Historia o contexto del dominio
- Anti-patrones comunes

## Anti-patrones

- Guía sin propósito claro
- Estructura desorganizada
- Mezcla de referencia con prescripción
