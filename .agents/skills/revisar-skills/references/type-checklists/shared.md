# Checklist compartido (todos los tipos)

Aplica en toda auditoría de cuerpo, independientemente del tipo clasificado:

- **Propósito de apertura — audiencia y tarea en un párrafo** (requerido)
  - Enlaza skills adyacentes si es parte de una cadena

- **Fronteras — acciones excluidas concretas o skills hermanos** (requerido)
  - Ver [direct-writing-guide.md](../direct-writing-guide.md)

- **Ruta de desconocidos — Preguntas abiertas y/o ask antes de proceder** (requerido)
  - Empareja cada regla de gap con ask, stop, o Preguntas abiertas

- **Links de recursos — `references/foo.md`, no `../_shared/` desde `SKILL.md`** (requerido)
  - Ver [resource-layout-guide.md](../resource-layout-guide.md)

- **Desacoplamiento de referencias — `references/` sin menciones directas a skills específicos** (recomendado)
  - El routing y las fronteras entre skills viven en `SKILL.md`; las referencias describen lógica de proceso

- **Links a skills hermanos cuando está en una cadena de workflow** (recomendado)
  - Requerido para orchestrator y composite
