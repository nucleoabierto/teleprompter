# Chat-gate

Skills cuyo entregable es chat-only con veredicto pass/fail o readiness.

## Checklist requerido

- Criterios de decisión claros
- Veredicto Ready for específico
- Output en chat estructurado
- Cuándo detener vs continuar

## Checklist recomendado

- Handoff block si es parte de workflow
- Estrategia de fallo para casos edge

## Anti-patrones

- Criterios de decisión ambiguos
- Veredicto Ready for genérico
- Chat sin estructura clara
