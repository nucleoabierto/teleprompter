# Autoevaluación Checklist: evaluar-alcance-idea

Después de completar la evaluación de alcance, responde estas preguntas:

1. **¿Evalué correctamente el alcance de la idea?**
   - [ ] Sí, clasifiqué como múltiples funcionalidades o funcionalidad única con justificación
   - [ ] No, la clasificación no está clara o falta justificación

2. **¿Dividí el alcance cuando fue necesario?**
   - [ ] Sí, generé roadmap de funcionalidades con prioridades relativas
   - [ ] No, no dividí o la división no es lógica

3. **¿Identifiqué las funcionalidades con alcance claro?**
   - [ ] Sí, cada funcionalidad tiene un alcance bien definido
   - [ ] No, los alcances están vagos o superpuestos

4. **¿Definí el value proposition para cada funcionalidad?**
   - [ ] Sí, cada funcionalidad tiene un valor principal claro
   - [ ] No, los value propositions no están claros

5. **¿Estimé el timeline de forma realista?**
   - [ ] Sí, el timeline es realista basado en el alcance
   - [ ] No, el timeline es demasiado optimista o pesimista

6. **¿Identifiqué las dependencias entre funcionalidades?**
   - [ ] Sí, las dependencias están claramente documentadas
   - [ ] No, las dependencias no están identificadas

7. **¿Definí el "Ready for" correctamente?**
   - [ ] Sí, apunta al siguiente paso correcto (priorizar-roadmap o evaluar-conectividad-tecnica), con variante (condicionado) si hay preguntas Importantes sin resolver
   - [ ] No, el "Ready for" no es claro, es incorrecto, o no refleja el estado de avance del gate

8. **¿El documento de salida es accionable?**
   - [ ] Sí, contiene recomendaciones claras y next steps
   - [ ] No, falta claridad en qué hacer después

9. **¿Ejecuté y documenté el gate de avance (Fase F)?**
   - [ ] Sí, el inventario de preguntas está completo, la alerta al usuario está documentada (si hubo), y el estado final de avance justifica el Ready for
   - [ ] No, omití el gate, no documenté el inventario, o no registré la alerta

10. **¿Clasifiqué las decisiones pendientes por severidad y las heredé al siguiente skill?**
    - [ ] Sí, cada decisión pendiente tiene severidad (Crítico/Importante/Menor) y las pendientes se documentan para herencia
    - [ ] No, las decisiones pendientes no están clasificadas o se pierden al avanzar

Si alguna respuesta es "No", revisa y completa antes de marcar el skill como terminado.
