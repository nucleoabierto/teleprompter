# Menú Ready for para creación de tickets

Elige exactamente una opción de este menú y explica por qué:

## Opciones

- `review-ticket-before-implementation` — El borrador necesita revisión de readiness antes de investigación o implementación
- `context-brief` — El ticket existe o el borrador es estable suficiente para construir un research brief cuando `TICKET-ID` se conoce
- `export-to-tool` — El borrador está listo para exportar a una herramienta de gestión específica
- `blocked` — INPUT faltante, Preguntas abiertas sin resolver, o ticket duplicado encontrado

## Uso en Fase B

Usa este menú en la Fase B — Redactar para declarar el estado del borrador después de la revisión.

## Uso en Fase C

Usa este menú en la Fase C — Escribir archivo local para recomendar el siguiente paso después de guardar el archivo:

- `review-ticket-before-implementation` — Puntuación del borrador ≥ 9 y el usuario aprobó creación
- `context-brief` — El ticket existe o el borrador es estable suficiente para construir un research brief cuando `TICKET-ID` se conoce
- `export-to-tool` — El borrador está listo para exportar a una herramienta de gestión específica
- `blocked` — INPUT faltante, Preguntas abiertas sin resolver, o ticket duplicado encontrado
