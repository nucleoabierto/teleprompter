# Dominios

Documentación viva del modelo del producto: un documento por dominio,
anclado al código que lo materializa.

- [001 — Paquete](001-paquete.md): el formato declarativo del
  manifiesto, sus rutas seguras y sus precondiciones.
- [002 — Instalación](002-instalacion.md): obtención, verificación,
  plan, ejecución y ciclo de vida de una instalación —actualización
  y retirada incluidas—.
- [003 — Registro](003-registro.md): el lock como memoria de lo
  instalado, la propiedad, la deriva, el territorio gestionado y las
  consultas sobre él.
- [004 — Resolución de conflictos](004-resolucion-conflictos.md): la
  política de colisiones, el diff que la informa y el respaldo que la
  hace reversible.
